# scalpelR

**scalpelR** is an R package designed for analyzing transcriptomics data, with a focus on isoform-level expression and alternative polyadenylation (APA) characterization at the single-cell level using isoform based Seurat object generated by SCALPEL (Nextflow)

## Installation

To install the latest version of **scalpelR** from GitHub, use the following command:

```R
# Install devtools if not already installed
install.packages("devtools")

# Install scalpelR from GitHub
devtools::install_github("Franzx7/scalpelR@dev")
```

## Functions

| Function           | Use                                                                                                      |
| ------------------ | -------------------------------------------------------------------------------------------------------- |
| `FindIsoforms`     | Differential isoform usage between groups of cells (`chisq` or `permutation` test), same method and table as the nf-core/scalpel `DIU_table.csv`: event type (tandem 3' UTR / alternative terminal exon), 3' UTR direction, isoform usage per group, replication across samples. |
| `plotUsage`        | Isoform usage (fraction of the gene UMIs) per group of cells and sample.                                  |
| `CoveragePlot`     | Read coverage of a gene per group of cells from the SCALPEL filtered BAM files (normalized by the number of cells), with the isoform structures. |
| `weightedUTR_cell` | Weighted 3' UTR length per cell (isoform usage x isoform 3' UTR length).                                  |
| `subsetBAM`        | BAM file of the reads of selected cells.                                                                 |
| `plotExpression`   | Isoform counts per group (violin / box plots).                                                           |

Example on mouse spermatogenesis (GSE104556): [10x downstream analysis](https://raw.githack.com/plasslab/nf-core-scalpel/refs/heads/dev/docs/vignettes/chromium_downstream.html).
